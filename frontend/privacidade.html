Seus dados e seu pedido.

O formulário solicita nome, telefone, serviço, data, horário e observação opcional para preparar um pedido de agendamento. Não informe dados sensíveis na observação.

Modo de apresentação

Sem API configurada, o site não envia o formulário para um servidor. Os campos ficam apenas na memória da página e não são armazenados pelo site neste navegador. Copiar o pedido coloca seu texto na área de transferência do dispositivo.

WhatsApp

Quando esse canal estiver ativado, o botão abre o WhatsApp com o texto do pedido, incluindo os dados preenchidos. Você decide enviar a mensagem. O WhatsApp aplica suas próprias condições de privacidade.

Envio online

Quando ativado, os dados são enviados à API da barbearia para tratar o agendamento. Antes de usar esse modo com clientes reais, a barbearia deverá informar aqui sua identificação, contato, prazos de retenção e procedimento para acesso, correção e exclusão dos dados.

Hospedagem

Os arquivos públicos são hospedados no GitHub Pages, que pode processar informações técnicas de acesso conforme suas próprias políticas. Este site não inclui ferramentas de publicidade ou análise de audiência.

Esta instalação está em preparação comercial. A política deve ser personalizada com os dados do estabelecimento antes da operação com clientes.
